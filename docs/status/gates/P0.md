## 4. Security findings
No open critical finding. Two findings are carried forward with owners:
- **Socket proxy does not check request bodies** (R-21). Mitigation task T-P6-24; alternative evaluated at P11. Must be closed before any untrusted test repository is run.
- **n8n blocks `$env` in Code nodes by default.** Enabling it exposes all environment variables to workflows. Secret handling for webhook HMAC is decided in P7.
- The Gemini API key was pasted into the chat transcript on 2026-11-10. It is stored only as a user environment variable, not in the repository. **The owner should rotate it.**
