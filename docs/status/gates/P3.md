## 2. Decisions taken
- Parser sidecar on an internal network; the API never calls it. Page images and DOCX layouts are produced at parse time and served from storage.
- DOCX layout: sanitized by an allow-list in the parser and shown in a sandboxed frame (`sandbox=""` + CSP), as data (JSON), never served as a page of the app origin.
- XLSX export with an own writer on Node zlib (no new dependency); CSV with BOM and formula-injection guard.
- UUIDv7 ids strictly increasing within a process (RFC 9562 counter): keeps insertion order where code sorts by id.
- External tracker items become draft requirements directly (no candidate review): the tracker is the authority for the text (BR-M04-8).
- Duplicate suggestions use pg_trgm (doc 09 §8 fallback); embeddings come with P5.
- New module `traceability` (doc 09 §5) used by requirements now and by test management from P4.
No ADR changed.
